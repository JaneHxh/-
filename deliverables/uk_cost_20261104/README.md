## 计算模型

累计可用数量 = 6月期初库存 + 7至10月全部到货。

未扣销量投入均价 = 累计投入金额 / 累计可用数量。

原始剩余数量 = 累计可用数量 - 6至9月Amazon销量 - 6至9月Temu销量。

最新库存成本USD/件 = (6月期初成本金额 + 7至10月到货成本金额 - SUM(6至9月销量 × 各月已记账成本单价)) / 原始剩余数量。

最新库存头程GBP/件采用相同公式，以GBP头程金额计算。只有原始剩余数量为正、相关批次金额完整且余额非负时才输出对应单价。原始负库存及负金额保留，不能以0掩盖；可结转库存取MAX(原始剩余数量,0)。

本次未提供10月销量，因此结果是“10月全部到货后、未扣10月销量”，并非11月期初库存。

## 如何查看

1. 先看“加权说明与参数”，币种USD已按用户确认设定。
2. “10月到货后最新加权”：M/N为不扣历史销量的投入均价，O/P为扣历史记账后的库存余额重分摊单价。两者不可混淆。
3. “批次入库与成本核验”：保留原录入价、订单核验价、有效成本和来源；按照货号＋PO匹配，不能用别的PO新报价替代旧批次。
4. “费用块分摊与校验”和“行头程计算”：保留币种、汇率、分摊分母及公式。
5. “6至10月逐月金额结转”：历史销量按原记账金额扣除，阶段负库存保留，可追查原历史早到计入时点。
