## 换汇解决了什么，还有什么要查

换汇解决了货值成本的币种错配，不能自动解决全部采购报价、到货时点和头程差异。原“74款换汇数值吻合”是发现币种的线索，现已按用户确认统一处理，不能继续称为74款错账。

原“36款头程”指历史已销每件头程与目前可追溯批次每件头程不同，并非货值GBP转USD的问题。AMZN7010200、AMZN5040126、AMZN10220137已按指示处理，另33款保留逐一说明。比如7010200的8月历史为GBP6.324466/件，用户已确认正确批次GBP1.7823/件，该项已冲回。其余参考范围只作核查线索，可能存在旧批次缺失、跨月到货或数量/体积/税金分摊差异，不直接据此覆盖历史。

82款说明表逐款区分已统一币种、已按指示调整、仍需核报价/时点或头程。恢复USD后仍有28款在某些月份缺少吻合的同期报价/到货依据，这是待核查线索，不能认定28款全错。

核对方式：先在33款表中选SKU和月份 → 找当月原头程分摊表及票号 → 核对应批次数量、体积、运费/税费及到货日期 → 确认历史应采用的加权头程 → 与“历史销量×原头程”比较金额后，再确定调整。没有凭证或批次明细时，不用当前批次价直接抹平旧账。
